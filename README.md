# Healith

## How to Run

1. Open this folder in Xcode (`File > Open...`).
2. Make sure you have Swift and Xcode installed (Xcode 14+ recommended).
3. Add two color assets to your **Assets.xcassets** color set, matching these:
   - **OnboardingGreen1**: `#009D7C`
   - **OnboardingGreen2**: `#027356`

4. Build and run the app — your onboarding splash screen will appear.

## File Structure
- `HealithApp.swift`: Main entrypoint.
- `OnboardingView.swift`: Splash/onboarding screen (fully reusable and customizable).

Feel free to extend the app with additional SwiftUI views!
